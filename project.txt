AI 공공시설 검색 에이전트 - 아키텍처와 파일 구성
==================================================

1. 전체 구조

프로젝트는 FastAPI 서버 하나에서 HTML 화면, 시설 검색 API, 에이전트 및 MCP 도구를 제공합니다.
화면은 Jinja2 서버 사이드 렌더링으로 만들고, 브라우저 JavaScript나 React는 사용하지 않습니다.
CSV 원본은 backend/data 폴더에 보관하며, ChromaDB 데이터베이스는 backend/chroma_db에 생성됩니다.

3. 데이터 및 검색 처리

1) Pandas가 UTF-8 CSV를 읽고 필수 열, 공백, 결측치를 정리합니다.
2) 구조화 검색은 지역(전국/서울/경기/서울+경기)과 시설명·시설 유형을 데이터프레임에서 필터링합니다.
3) 임베딩 스크립트는 시설의 이름, 유형, 장소, 주소, 운영·이용 정보를 검색 문서로 합칩니다.
4) Sentence Transformers 다국어 임베딩으로 문서를 벡터화하고 ChromaDB 영속 컬렉션에 저장합니다.
5) 벡터 검색은 질문의 의미 유사도를 기준으로 결과를 찾으며 선택된 지역 조건도 적용합니다.
6) 상세 화면은 원본 CSV의 해당 시설 레코드를 표시합니다.

4. RAG 및 에이전트 동작

사용자가 질문을 보내면 에이전트는 설정된 OPENAI_API_KEY가 있을 때 모델의 도구 호출을 처리합니다.
에이전트가 사용할 수 있는 도구는 시설 검색(search_facilities)과 상세 조회(get_facility_details)뿐입니다.
도구 구현은 MCP 서버도 공유하므로 같은 검색 동작을 MCP 클라이언트에서도 사용할 수 있습니다.
모델 키가 설정되지 않은 경우 벡터 검색 결과를 근거로 간단한 RAG 응답을 만듭니다.
ChromaDB를 아직 만들지 않았다면 임베딩 스크립트를 먼저 실행하도록 안내합니다.

5. MCP 실행

프로젝트 루트에서 backend 폴더를 기준으로 `python -m app.mcp_server`를 실행하면
표준 입출력(stdio) MCP 서버가 시작됩니다. MCP 클라이언트 설정에는 backend 폴더와
해당 Python 실행 파일을 지정합니다.

6. 화면 구성 및 실행

- `/`: 지역과 검색 방식을 선택하는 검색 폼, 에이전트 질문 폼
- `/search`: 시설명·유형 구조화 검색 또는 벡터 유사도 검색 결과 목록
- `/facilities/{id}`: 운영 시간, 이용료, 주소, 연락처 등 상세 정보

실행 방법:
1) `cd backend`
2) `python -m pip install -r requirements.txt`
3) `python scripts/embed_data.py` (벡터 검색과 RAG를 위한 최초 1회 및 CSV 갱신 후 실행)
4) `uvicorn main:app --reload`
5) 브라우저에서 http://127.0.0.1:8000 접속

구조화 검색 및 상세 정보는 CSV만으로 동작합니다. 벡터 검색/RAG는 임베딩 완료 후 동작하며,
OPENAI_API_KEY는 모델 기반 도구 선택을 사용할 때만 필요합니다.

7. 상세 검색 필터 추가

- 시설명, 개방장소명, 시설 유형을 각각 검색 조건으로 사용할 수 있습니다.
- 기존 시설명 또는 시설 유형 검색 호환을 위해 q 검색어도 시설명, 개방장소명, 시설 유형에서 찾습니다.
- 지역은 전국, 서울특별시, 경기도 및 실제 주소가 확인되는 전국 시·도 단위로 선택합니다.
- 이용료는 실제 CSV의 유료사용여부 열 값 Y를 유료, N을 무료로만 구분합니다.
- 운영일은 평일운영시작시각/종료시각 또는 주말운영시작시각/종료시각의 값이
  00:00 또는 0:00이 아닌 실제 값이 있는 경우 운영 정보가 있는 것으로 판단합니다.
- 여러 조건은 AND 방식으로 동시에 적용합니다.
- 검색 초기화는 처음 화면으로 돌아가 전국/전체 조건으로 되돌립니다.
- 결과가 없으면 안내 메시지를 표시하고, 구조화 검색에서는 전체 일치 건수를 표시합니다.
- 주소, 운영시간, 이용료 열이 없거나 결측인 레코드는 빈 값 또는 미등록으로 안전하게 표시하며
  존재하지 않는 값을 추측하거나 임의로 생성하지 않습니다.

  시설명, 장소명, 지역, 시설 유형, 이용료, 운영일 및 검색 방식 입력과 초기화 버튼을 제공합니다.

  기존 벡터 검색 기능을 유지하면서 전국 시·도 지역 필터를 추가합니다.

10. 시설 상세정보 기능

- 검색 결과의 시설명 링크는 CSV 행에 부여한 내부 ID(/facilities/{id})로 상세 페이지를 조회합니다.
- 시설명만으로 조회하지 않으며, 동일한 시설명이 있어도 각 행의 고유 내부 ID로 정확한 레코드에 접근합니다.
- 상세 페이지는 다음 실제 CSV 컬럼만 사용해 항목별로 구분합니다.
  시설 기본정보: 개방시설명, 개방장소명, 개방시설유형구분
  위치: 소재지도로명주소, 소재지지번주소
  운영: 평일운영시작시각, 평일운영종료시각, 주말운영시작시각,
        주말운영종료시각, 휴관일
  이용료 및 인원: 유료사용여부, 사용료, 수용가능인원수, 면적
  부대시설: 부대시설정보
  관리기관: 관리기관명, 사용안내전화번호
  홈페이지 및 기준일: 홈페이지주소, 데이터기준일자
- CSV에 운영기관명 또는 관리기관전화번호라는 별도 컬럼이 없으므로 실제 컬럼인
  관리기관명과 사용안내전화번호만 표시합니다.
- 결측값과 빈 문자열은 "정보 없음"으로 표시합니다.
- 유료사용여부 Y/y는 유료, N/n은 무료로만 변환하며 사용료는 원본 값을 그대로 표시합니다.
- 홈페이지주소가 http:// 또는 https://로 시작하는 경우에만 새 창 링크를 표시합니다.
- 검색 결과 화면의 전체 요청 주소를 back 매개변수로 전달해 상세 페이지의
  "검색 결과로 돌아가기" 버튼에서 기존 검색 조건과 페이지 상태로 돌아갑니다.

11. 지도 기반 시설 검색 기능

- 검색 결과 화면(/search)은 검색 목록과 Leaflet 지도를 나란히 표시합니다.
- 모바일 화면에서는 지도와 목록이 세로로 배치됩니다.
- 지도 라이브러리는 Leaflet 1.9.4와 OpenStreetMap 타일을 사용하며 별도 API 키가 필요 없습니다.
- 지도 타일 또는 CDN을 불러오지 못해도 기존 HTML 검색과 상세 화면은 계속 동작합니다.
- CSV의 위도와 경도 열을 사용합니다.
- 위도는 33~43 범위, 경도는 124~132 범위의 수치만 지도 마커에 표시합니다.
- 좌표가 빈 값이거나 변환할 수 없거나 범위를 벗어나면 검색 목록에는 유지하되 지도 마커는 제외합니다.
- 구조화 검색과 벡터 검색으로 필터링된 결과만 get_valid_map_markers에 전달하므로 지도 마커는 검색 목록과 동기화됩니다.
- 마커 팝업은 시설명, 시설 유형, 주소, 평일 운영시간, 이용료를 표시하고 상세정보 화면 링크를 제공합니다.
- 목록의 "지도에서 위치 보기" 버튼은 해당 시설의 마커를 지도 중앙으로 이동하고 팝업을 엽니다.
- 검색 조건을 바꾸거나 초기화하면 /search가 새로 요청되어 목록과 마커가 함께 갱신됩니다.
- 마커가 없으면 지도 기본 위치와 "표시할 유효한 좌표가 있는 시설이 없습니다" 안내를 표시합니다.

13. AI 맞춤형 시설 추천 기능

- AI 에이전트 질문 화면을 공공시설 맞춤 추천 화면으로 사용합니다.
- 자연어 질문에서 지역, 시설 유형, 무료/유료, 평일/주말, 저녁 이용 가능 여부,
  최소 수용인원 조건을 데이터에 근거해 추출합니다.
- CSV 시설 유형 목록과 실제 지역명만 선택하며, 질문에 없는 조건은 임의로 추출하지 않습니다.
- 구조화 검색은 기존 CSV 필터를, RAG는 기존 ChromaDB 벡터 검색을 보조적으로 사용합니다.
- 구조화 검색과 벡터 검색 결과의 시설 ID를 기준으로 중복 제거한 뒤 추천 카드로 비교합니다.
- 추천 카드에는 시설명, 유형, 주소, 평일/주말 운영시간, 휴관일, 이용료, 수용인원,
  지역·유형·이용료·운영일·수용인원 일치 여부와 추천 이유를 표시합니다.
- 원본 CSV에 누락된 값은 "정보 없음" 또는 확인 불가 문구로 표시하며 임의로 추측하지 않습니다.
- 조건에 맞는 시설이 없으면 지역, 이용료 또는 시설 유형 변경을 안내합니다.
- 상세정보와 지도 기능은 각 시설의 내부 ID와 기존 /facilities 및 /search 경로를 사용합니다.
- MCP 도구 search_public_facilities는 지역, 시설 유형, 이용료, 운영일, 시설명 및 장소명 필터를
  기존 구조화 검색 도구에 전달할 수 있습니다.
- OPENAI_API_KEY가 없으면 기존 RAG 검색을 보조로 사용하는 로컬 추천과 필터 검색을 사용합니다.

15. 공공시설 통계 대시보드

- /dashboard 별도 메뉴에서 지역과 시설 유형 필터가 적용된 Pandas 통계를 제공합니다.
- 지역 필터는 전국, 서울특별시, 경기도 및 기타 시·도 옵션을 사용합니다.
- 시설 유형 필터는 CSV의 개방시설유형구분 실제 값만 사용합니다.
- 요약 카드: 전체 시설 수, 시설 유형 수, 관리기관명 기준 제공기관 수,
  유료사용여부 Y/y 유료 수, N/n 무료 수를 표시합니다.
- 이용료 정보 없음은 Y/N 외의 빈 값 또는 확인되지 않은 값을 원본 기준으로 집계합니다.
- 평일 운영 시설과 주말 운영 시설은 각각 시작시각이 빈 값이나 0:00/00:00이 아닌 행을 집계합니다.
- 운영정보 없음은 평일과 주말 시작시각 모두 운영시간이 없는 행을 집계합니다.
- 지역별 집계는 기존 시설 주소 기반 _region 파생값을 사용합니다.
- 제공기관별 집계는 관리기관명 실제 컬럼을 사용하며 빈 값은 제외합니다.
- 데이터 기준일자는 데이터기준일자 실제 값만 중복 제거해 표시합니다.
- Chart.js 4.4.7 CDN을 사용하며 차트 라이브러리 로드 실패 시 수치 표와 요약 카드는 유지됩니다.
- 차트는 지역 막대그래프, 시설 유형 원형그래프, 이용료 도넛그래프,
  제공기관 수평 막대그래프를 제공합니다.
